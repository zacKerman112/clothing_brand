# Clothing Shop Project 

Навчальний проєкт на Django — інтернет-магазин одягу з кастомною системою реєстрації.

## Основні функції
- **CRUD для товарів:** створення, перегляд, оновлення та видалення одягу.
- **Custom User:** розширена модель користувача з аватаром та перевіркою віку (18+).
- **Пошук та фільтрація:** швидкий пошук товарів за назвою та категоріями.
- **Охайний інтерфейс:** дизайн на базі Bootstrap 5.
